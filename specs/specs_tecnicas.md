## Índice de Artefactos Ejecutables (`proyecto/specs/`)
1. **Contratos de Interfaz (`contratos_api/`):** Esquemas OpenAPI / JSON Schema con validación estricta.
2. **Reglas de Negocio (`reglas_negocio/`):** Tablas de verdad deterministas y algoritmos de validación.
3. **Esquemas de Datos (`esquemas_bd/`):** DDLs relacionales, analíticos o NoSQL.
4. **Criterios de Aceptación (`criterios_gherkin/`):** Escenarios `.feature` automatizables.
5. **Datos Simulados (`mocks_dummy_data/`):** Payloads sintéticos de prueba (casos exitosos y de error).
